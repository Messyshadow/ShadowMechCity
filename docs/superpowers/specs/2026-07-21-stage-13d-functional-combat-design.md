# 阶段 13D：功能性战斗、打击反馈与试玩阻塞修复设计

日期：2026-07-21  
状态：待策划复核

## 1. 目标

13D 不只统一命中停顿、硬直、击退、镜头和技能特效，还要让武器技能参与银河恶魔城式探索。战斗技能在敌人身上有明确流派，在场景中提供可读、可选、可回溯的功能；所有新功能必须兼容既有炸弹、水下推进器、攀墙、滑翔翼和暗影滑翔翼，不破坏旧关卡通路。

## 2. 设计原则

1. **主线不单点软锁**：关键路径沿用既有永久能力；武器功能优先用于捷径、秘室、资源和战斗优势。
2. **一类障碍允许多解**：例如脆岩墙可被炸弹炸开，也可由装备铁锤后的指定蓄力技击碎。
3. **武器身份不只看伤害**：每类武器拥有战斗资源、移动方式、环境互动和独立视听语言。
4. **先提示，再考验**：首次遇到交互物时同时展示图形、文字、按键和方向；成功一次后缩减提示。
5. **兼容旧存档**：不删除或改名既有 ability、weapon、skill id；新增字段采用默认值和幂等迁移。

## 3. 13D 分批范围

### 13D.1 试玩阻塞修复

- 冲刺相位屏障增加远距动态箭头、冲刺图标和能量流向。
- 玩家进入提示范围后显示高对比文案：`[Shift] 向右/向左冲刺穿越相位屏障`。
- 普通移动撞击屏障时触发红色拒绝闪光、短震动与“普通移动无法穿越”提示，同时高亮冲刺键。
- 首次成功穿越后记录教学状态，后续只保留简洁图标。
- Boss 战期间在入口设置“紧急撤离装置”，靠近显示 `长按 B 撤离 Boss 战` 和进度环。
- 暂停菜单同步提供“撤离 Boss 战（测试版）”；撤退回进入 Boss 房前的安全房，不发奖励、不标记击败。
- 测试版继续采用死亡后重建当前房间；正式版最近存档点重生仅预留数据接口，本阶段不切换规则。

### 13D.2 六武器战斗身份与功能

每类武器保留现有基础攻击，并扩展为起手、位移、控制、核心、终结五类主动节点。

#### 刀剑：剑气与精确反击

- 战斗：雷轮风暴、无影龙牙斩、天穹裂闪、影返·瞬狱、终式·苍龙破。
- 功能：剑气可隔空触发部分机关；完美反击可反射轻型投射物。
- 限制：不承担破墙和长距离移动，保持均衡型定位。

#### 铁锤：蓄力、破甲与环境粉碎

- 战斗：熔炉震击、磁暴重锤、裂地追击、泰坦坠落、终式·机械天崩。
- 功能：装备铁锤时，完整蓄力重击和指定砸地技能可击碎“脆岩/松动机械墙”。
- 兼容：炸弹仍能炸开同类墙，且无需装备铁锤；部分远程炸点只允许炸弹，避免铁锤完全替代炸弹。
- 反馈：蓄力分三级，使用轮廓增亮、蒸汽泄压、音高递增和地面裂纹明确阶段。

#### 蒸汽枪炮：热量、后坐力和喷射推进

- 战斗：爆燃霰射、穿甲磁轨炮、火箭跃迁、过载炮台、终式·蒸汽歼灭。
- 功能：在标记的高压蒸汽区消耗热量进行短时悬浮/横向喷射，抵达普通跳跃够不到的侧台。
- 限制：只能在蒸汽环境锚点或技能持续时间内使用，不成为全地图无限飞行。

#### 双刀：高速连击、残影与钩索弹跳

- 战斗：影轮绞杀、双月追魂、瞬身背刺、血舞千刃、终式·夜叉无间。
- 功能：解锁身法节点“影索回弹”后，可抓取带紫色机械环的锚点；接触后弹射而非静止悬挂。
- 操作：方向键决定离锚方向；合适时机再次跳跃获得强化弹射。
- 限制：只响应明确锚点，不允许抓取任意墙面；攀墙和二段跳仍保有用途。

#### 长枪：钻击、突进与浮空控制

- 战斗：雷霆贯星、升龙破阵、回马裂空、龙骑冲锋、终式·天穹贯日。
- 功能：“齿轮钻突”可穿过带螺旋纹的薄型机械障碍，并对装甲敌人持续破甲；“旋枪升流”命中敌人或气流节点后获得短时向上浮空。
- 限制：钻击不能破坏炸弹墙；浮空高度和次数受资源限制，不能无限滞空。

#### 弓弩：瞄准、标记与远距机关

- 战斗：影缚箭雨、爆裂弩矢、穿云狙击、机械猎鹰齐射、终式·星陨天罗。
- 功能：远距离触发靶盘、切断吊索、固定临时平台；标记弱点后为其他武器提供一次增伤窗口。
- 限制：不能直接替代炸弹破墙和近战重型机关。

## 4. 环境能力扩展

- **水下推进**：既有 `aqua` 保持全向游动和抗水流能力；技能节点增加短冲、转向保护和击退水下敌人的推进波。
- **蒸汽飞行**：暗影滑翔翼在上升气流中继续强化；蒸汽枪炮提供短时主动喷射，两者可连携但用途不同。
- **勾索弹跳**：归入身法页，双刀装备时获得更高弹射效率，但基础锚点能力不强制玩家长期装备双刀。
- **双解破墙**：障碍数据声明 `break_methods`，允许 `bomb`、`hammer_charge` 或特定组合；旧 `breakables` 默认仍只需兼容炸弹。
- **技能门视觉语言**：脆岩为橙黄裂纹、钻击壁为螺旋齿纹、钩索锚为紫色环、弩机关为青色靶盘、蒸汽锚为白蓝压力喷口。

## 5. 技能树与右侧预览

- 战斗页按刀剑、铁锤、蒸汽枪炮、双刀、长枪、弓弩六个分支展示。
- 节点详情明确标注：主动/被动、地面/空中条件、组合输入、资源消耗、功能用途、可交互障碍。
- 右侧预览必须展示角色、训练假人和环境目标，完整播放起手、移动、命中、环境互动、收招五段。
- 预览示例：铁锤先命中敌人造成硬直，再砸开裂墙；长枪钻过薄壁后旋枪浮空；双刀抓锚后按方向弹射。
- 未解锁节点仍可预览，但使用灰蓝滤镜并显示前置条件。

## 6. 打击反馈统一

- 轻击、重击、破甲、暴击和终结使用不同命中停顿档位，Boss 对停顿和击退采用独立缩放。
- 受击硬直由攻击标签与敌人韧性共同决定，不允许无限连锁锁死 Boss。
- 材质分为血肉、金属、岩石、能量护盾和虚空五类，分别选择粒子、音色与火花颜色。
- 镜头冲击按技能层级限制幅度；连续攻击合并震动，避免画面持续抖动。
- 特效分层为预警、攻击主体、命中、残留四层，危险预警永远高于装饰粒子。

## 7. 数据与架构

- 技能数据增加 `interaction_tags`、`resource_rule`、`preview_stages` 和 `environment_use`，旧节点缺省为空。
- 可破坏物增加允许手段集合，不在武器脚本中硬编码房间 id。
- 钩索锚、钻击壁、蒸汽锚和远程机关采用独立组件，通过统一 `try_skill_interaction()` 协议响应。
- Main 记录 `boss_entry_room`，仅在进入未击败 Boss 房时更新；撤退复用正常房间入口定位。
- 教学状态持久化，旧存档缺失时按未教学处理。

## 8. 验收标准

1. 坍塌隧道冲刺门在 1280×720 下无需试错即可理解按键和方向。
2. 普通移动撞门、成功冲刺穿门均有不同且清晰的反馈。
3. 岩核机甲巨兽 Boss 战可从场景装置和暂停菜单安全撤退，不能获得击败奖励。
4. 六类武器各至少有一个代表性功能技能可实战并可在技能页完整预览；后续按同一框架扩展至每类五个主动技能。
5. 炸弹与铁锤均能处理允许双解的脆岩墙；旧炸弹墙行为不退化。
6. 水下推进、蒸汽喷射、钩索弹跳与长枪钻击/浮空均不能造成主线软锁或无限移动。
7. 运行全部自动测试、编辑器解析和主场景错误扫描，结果为 0 `ERROR` / `SCRIPT ERROR`。
8. 使用项目 godot-capture 工作流抓取并目视检查冲刺门、Boss 撤退、六武器技能预览和至少三类环境互动 PNG。
9. 更新 `docs/qa/13D-review.md` 与 `docs/DEV_PLAN.md`，并导出发布包到 `E:\Godot\release`。

## 9. 明确不在本批完成的内容

- 正式版最近存档点死亡重生规则切换。
- 六类武器全部五个技能一次性达到最终商业美术品质；13D 先完成可扩展框架和每类代表技能，再逐批补齐。
- 任意表面自由勾索、无限飞行或任意墙体破坏。
