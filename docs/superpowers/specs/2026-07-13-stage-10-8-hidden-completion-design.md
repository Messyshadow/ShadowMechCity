# 阶段 10.8：全区域隐藏探索与完成度设计

日期：2026-07-13

## 目标与依据

本阶段依据 `暗影机械城_GDD(2).md`、`区域设计模板.md` 和 `技能系统_v2_设计定稿.md`，为当前商业 Demo 建立可扩展的隐藏房和完成度闭环。正式 GDD 每区域 5–10 个隐藏房属于 300+ 房间成品规模；当前版本采用兼容缩放，不伪造该体量，也不删除阶段 8.4 已有收集点。

## 交付范围

新增七间独立主题秘室，每个区域一间：

| 区域 | 秘室 | 入口能力 | 核心体验 |
|---|---|---|---|
| 中央枢纽 | 遗失档案库 | 攀墙 | 返回初始区域后的高处回溯 |
| 废铁矿坑 | 熔脉私藏间 | 炸弹 | 爆破机械暗墙与熔岩跳台 |
| 蒸汽铸造厂 | 废热回收仓 | 冲刺 + 炸弹 | 传送带、蒸汽间歇与暗墙组合 |
| 腐化水道 | 沉没蓄水池 | 水下推进器 | 逆流潜行与水下奖励 |
| 遗迹神殿 | 星轮观测室 | 二段跳 + 攀墙 | 垂直符文平台谜题 |
| 虚空要塞 | 裂隙观星台 | 暗影滑翔翼 | 强风滑翔与高空落点 |
| 暗影王城 | 君王遗骨库 | 全六能力 | 终局综合能力验证 |

秘室是 `Rooms.ROOMS` 中的真实房间，拥有独立 `map` 坐标、主题地标、平台路径、宝箱或收藏品以及返回门。入口在主房中使用 `hidden: true` 标记；玩家靠近仍可读到微弱主题提示，进入后才在地图上永久显示隐藏连接，避免地图提前剧透。

已有生命碎片和隐藏龛全部保留。虚空要塞与暗影王城新增至少一个能力门控收集点，使七大区域均有回溯奖励。隐藏房与隐藏龛合计至少 15 个可发现点。

## 收集与持久化

完成度追踪以下六类：

1. 房间探索：`visited / Rooms.ROOMS.size()`，包含已发现秘室。
2. 隐藏秘室：已进入的 `hidden_room` 数量 / 7。
3. Boss：`items` 中 `boss_` 前缀 / 当前 Boss 总数。
4. 宝箱：永久开启 ID / 房间数据中的唯一宝箱总数。
5. 武器：`unlocked_weapons / Weapons.LIST.size()`。
6. 收藏品：`collected / secrets 总数`，包含生命碎片及记忆核心。

总完成度以所有可计数项目的“已完成数量之和 / 总数量之和”计算，避免小类别获得过高权重。支线任务在阶段 12 尚未实现，本阶段明确不把它放入分母，防止永远无法达到 100%。

新增永久 `opened_chests` 存档字段。旧存档缺失该字段时迁移为空集合；已开启宝箱不在读档后重复出现。隐藏房发现记录复用 `visited`，不创建重复状态源。

## 地图与界面

M 键大地图增加左侧完成度仪表：总百分比、房间、秘室、宝箱、Boss、武器、收藏品。每项显示 `当前 / 总数` 和细进度条。

已发现隐藏房使用紫色虚线边框和菱形标记；未发现隐藏房及连接完全不绘制。普通小地图保持简洁，只在完整地图显示详细统计和图例。

## 奖励原则

- 独立秘室：固定主题宝箱 + 记忆核心，终局秘室可给传奇装备。
- 隐藏龛：生命碎片、金币或普通装备，不重复刷取永久收藏品。
- 奖励不新增战斗强度硬门槛，不要求使用秘室内奖励才能离开。
- 技能输入、MP/怒气和武器联动保持技能系统 v2 定稿，不在 10.8 改键或重做战斗。

## 数据与代码边界

- `scripts/rooms.gd`：房间、隐藏入口、收藏品与地图坐标的唯一内容数据源。
- `scripts/completion.gd`：纯统计模块，从房间数据和 Game 状态计算分项及总完成度。
- `scripts/game.gd`：持久状态、旧存档迁移和宝箱开启记录。
- `scripts/main.gd`：生成隐藏入口、进入秘室后发现状态和 QA 定位。
- `scripts/map_panel.gd`：只负责绘制统计与已发现地图，不复制统计规则。
- `scripts/pickup.gd`：记忆核心拾取表现与一次性收集。

任何物理信号内的房间切换、碰撞节点创建或禁用继续使用 deferred 调用，遵守区域模板的物理安全红线。

## 测试与验收

自动契约测试至少验证：七间秘室存在且主题齐全、隐藏入口双向有效、每个区域有收藏点、能力要求合法、宝箱 ID 唯一、完成度分母非零、旧存档迁移字段存在、100% 状态能准确得到 100。

运行源码编译 Godot，扫描全部 `ERROR` / `SCRIPT ERROR`。使用 godot-capture 实拍：至少七间秘室各一张、一个隐藏入口发现前后、大地图完成度面板、一个水下秘室和一个滑翔秘室的动作连拍。逐张查看可达性、平台间距、入口辨识、拾取物摆放和地图遮挡，修复后写入 `docs/qa/10.8-review.md`。

## 非目标

- 不在单阶段扩张到正式成品的 35–70 间隐藏房。
- 不实现阶段 12 的支线任务统计。
- 不重构当前程序化房间为 TileMap，也不替换技能系统。
- 不删除或覆盖用户的未跟踪素材和策划文档。
