# 技能演示强化与双向机械竖井设计

日期：2026-07-28

对应批次：13.4.1、13.3.1

## 目标

解决两个策划试玩问题：

1. 技能树右侧预览虽然会播放角色动作，但缺少技能主体、命中和残留，难以看出技能效果。
2. 上下行通道已有机械入口和下落过渡，但上行缺少可操作的竖井体验，下行墙跳、踏板和镜头过程仍需统一强化。

本批次不进入阶段 14。阶段 14 继续保留为技术发布阶段。

## 13.4.1 技能系统与演示

### 技能扩充

保留现有 `J` 普攻、`K` 重击、`方向 + K`、双击方向后 `K` 和满怒气 `V`，不增加新的基础按键。

每个武器家族补齐可见的主动/组合节点，使战斗页不再出现只有入口或被动节点的分支：

| 家族 | 新增或强化技能 | 输入 | 主要表现 |
| --- | --- | --- | --- |
| 刀剑 | 雷霆旋风斩 | `J → J → J` | 环身双层剑弧、雷纹命中圈 |
| 刀剑 | 无影狂龙斩 | `→ → + K`，随后 `V` | 高速残影穿身、龙形终结剑光 |
| 铁锤 | 熔核震爆 | `↓ + K` | 蓄力压缩、地裂冲击柱、碎片残留 |
| 铁锤 | 磁轨飞锤 | `→ → + K` | 短距突进、横向重锤轨迹、击退 |
| 蒸汽枪炮 | 过压升焰 | `↑ + K` | 蒸汽反冲升空、锥形喷流 |
| 蒸汽枪炮 | 贯星压力炮 | `↓ + K` | 直线压力束、尾流和终点爆破 |
| 双刀 | 镜影风暴 | `↓ ↓ + K` | 双残影交叉、多段环切 |
| 双刀 | 裂空瞬狱 | 满怒气 `V` | 四向刃痕锁定后同步收束 |
| 长枪 | 天轮升龙 | `↑ + K` | 螺旋枪轨上挑、浮空提示 |
| 长枪 | 龙脊钻星 | `→ → + K` | 齿轮钻头轴线、贯穿尾迹 |
| 弓弩 | 裂隙箭雨 | `↓ ↓ + K` | 扇形标线、延迟落箭 |
| 弓弩 | 猎杀终端 | 满怒气 `V` | 准星锁定、三段穿透射击 |

新增节点是对现有实际招式槽位的命名、成长和教学补齐；伤害仍由 `player.gd` 现有六武器技能路径处理，避免创建第二套战斗系统。需要新增视觉差异时，通过共享特效配置扩展，不复制命中逻辑。

### 预览结构

`SkillPreview` 继续使用独立 `SubViewport`，不生成伤害区域、不扣除技力/怒气、不触碰存档。

预览高度由 150 提升到约 190 像素，角色与假人放大，减少无效空白。每次选中节点都会循环以下五阶段：

1. 起手：输入标签、武器蓄光和危险范围预警。
2. 技能主体：剑弧、地裂、蒸汽束、双刀交叉、长枪轴线或弓弩弹道。
3. 命中：假人闪白/受击偏移、命中环和短促画面冲击。
4. 残留：雷纹、裂缝、蒸汽、刃痕、钻轨或准星淡出。
5. 收招：角色回位、武器回到待机姿态，停顿后重新循环。

被动技能不伪装成主动攻击：预览显示“触发条件→生效反馈→数值变化”三段说明，并使用较克制的角色光效。

### 数据边界

技能节点增加以下可选字段：

- `preview_pattern`：`slash_spin / shadow_dash / ground_smash / pressure_beam / cross_slash / spear_drill / arrow_rain / passive`。
- `preview_intensity`：`basic / signature / ultimate`。
- `preview_color`：覆盖武器家族默认颜色。
- `preview_stages`：继续兼容既有功能型技能的五阶段预览。

共享配置只描述颜色、形状、层级、时序和预算；真实伤害与输入判定仍由玩家战斗代码负责。

## 13.3.1 双向机械竖井

### 下行

- 继续由 `[E / Enter]` 主动进入，避免误触。
- 使用 620px 左右的可操作井道，保留真实玩家物理。
- 两侧是连续可贴墙表面，允许墙滑和墙跳。
- 三组错层单向踏板交替布置，但中央始终保留快速下落通线。
- 镜头纵向缓动跟随，最大下落速度沿用 `SHAFT_FALL_SPEED`。
- 触底后再切换房间；中途不关闭玩家物理。

### 上行

- 上行门不再只显示悬空圆环后立即切房。
- 进入约 420–520px 的镜像短井道，玩家从底部开始。
- 两侧连续墙面支持基础墙跳；取得攀墙能力后可直接攀爬，属于更快捷路线而非硬门槛。
- 设置三处错层落脚板，跳跃能力不足时仍可逐层上行。
- 到达顶部触发区后切换目标房间，并从对应出口落脚点出现。
- 保留退出提示；不会把普通横向门改为竖井。

### 视觉

- 延续暗黑机械/赛博蒸汽朋克主题：厚井沿、铆钉墙板、维护梯、悬链、导向灯、雾汽和深度渐暗。
- 不直接复制《暗影火炬城》素材，只参考其“入口可读、镜头连续、墙面可操作”的设计语言。
- 按房间主题改变灯色和雾色，碰撞几何保持一致。

## 兼容性

- 不改现有技能 ID；新增技能使用新 ID，旧存档缺省为 0 级。
- 不改变旧武器解锁、能力门、任务和收藏数据。
- `glide`、`shadow_glider`、`wall_climb` 等已有能力语义不变。
- 已有下行入口、隐藏门和传送阵交互继续使用 `[E / Enter]`。
- 横向房门和 Boss 门不纳入双向竖井。

## 测试与验收

### 自动化

- 新技能 ID 唯一、前置存在、六家族均包含主动/组合/终结表现。
- 所有新增节点具有输入、用途、预览模式和强度字段。
- 预览不得创建 `Area2D`、不得调用资源消耗或保存接口。
- 下行井道保留墙面、中央通线和错层踏板。
- 上行井道具有底部出生、可墙跳表面、至少三处落脚板和顶部完成触发。
- 旧入口、存档和阶段测试全部继续通过。

### godot-capture

- 六武器各抓取至少一个新增技能的右侧预览关键帧。
- 被动技能单独抓取，确认不会误导为主动攻击。
- 下行与上行各抓取至少六帧连续 PNG，确认镜头移动、墙面位置、踏板可达和角色未穿模。
- 逐张目视后修复遮挡、缩放、碰撞、无变化连拍及文字裁切。
- 扫描全部 `ERROR` / `SCRIPT ERROR`。

### 发布

- 编写 `docs/qa/13.4.1-review.md` 与 `docs/qa/13.3.1-review.md`。
- 更新 `docs/DEV_PLAN.md`。
- 使用源码编译 Godot release 模板导出到 `E:\Godot\release\暗影机械城`。
- 发布版运行 240 帧无可执行错误后提交 Git。
