# 下行入口与发布修复设计

## 目标

修复地下水道返回矿坑时的平台链容错不足，并确保发布目录中的 EXE 是由当前源码 Godot 编译的游戏模板，而不是旧编辑器程序。

## 设计

- 地下水道采用 5 级重叠单向踏板，从地面连续通到 x=600 的顶部出口；相邻高度差不超过 90 像素，横向间隔不超过 40 像素。
- 下行入口保留 180 像素宽实体井口，增加门楣、支撑梁、护栏、方向灯与井内踏棍，使入口在矿坑和水道主题下都具有明确体积与落点。
- 编译 Godot 源码的 `template_release`，在导出预设中显式引用该模板，然后生成新的 `ShadowMechCity.exe` 与 PCK。
- 验收包括静态契约、全项目错误扫描、地下水道实际 PNG 检查、发布 EXE 启动截图和文件时间/哈希记录。

## 边界

不改变旧存档能力、不删除未跟踪素材、不重构无关房间；发布仍保持 EXE + PCK 形式。
