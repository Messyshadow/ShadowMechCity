# 传送阵与隐藏入口交互设计

日期：2026-07-18  
建议阶段编号：10.9  
状态：已确认交互方向，待用户复核书面规格

## 1. 目标

在不破坏现有房间链、下行竖井和七个阶段 10.8 秘室的前提下，将“上下门与隐藏门碰到即传送”升级为可识别、可预期的主动交互：玩家靠近后看到明确按键提示，按 `E / Enter` 才进入。

本批只处理传送入口交互和表现，不新增快速旅行菜单，不重做装备系统，不扩建新区域房间。

## 2. 入口分类

### 2.1 自动过门

- 普通 `left` / `right` 房间门继续使用现有 `body_entered` 自动切换。
- 保持横向探索节奏，不要求每个房间边缘都额外按键。
- 锁门和能力门仍先执行现有条件检查。

### 2.2 主动交互入口

以下入口必须靠近后按 `interact`（默认 `E / Enter`）触发：

- `up` 传送阵；
- `down` 下行竖井；
- 所有带 `hidden: true` 的隐藏入口；
- 后续在门数据中显式声明 `trigger_mode: "interact"` 的特殊入口。

默认规则由门方向和 `hidden` 元数据推导，避免一次性改写全部房间数据；显式字段可覆盖默认值，便于后续特殊关卡扩展。

## 3. 玩家提示

### 3.1 正常入口

玩家进入交互范围后，在入口上方显示暗钢提示条与键帽：

- 普通传送阵：`[E / Enter] 启动传送阵`；
- 下行竖井：`[E / Enter] 向下进入`；
- 未探索隐藏入口：`[E / Enter] 进入隐藏回响`；
- 已探索隐藏入口：`[E / Enter] 前往 <房间名称>`。

提示条淡入，离开范围淡出；同一时间只显示离玩家最近的一个入口提示。

### 3.2 条件不足

能力条件不足时提示仍可见，但改为紫灰锁定状态并直接列出缺少内容，例如：

`需要：暗影滑翔翼 / 攀墙`

玩家按下交互键时不传送，播放短促的锁定音效与一次轻微提示闪烁，不重复刷屏。

### 3.3 输入冲突

- 入口交互只在玩家处于范围内、没有打开菜单、对话或演出时响应。
- NPC、剧情对话和入口同时可交互时，已打开的对话/演出优先；入口不抢输入。
- 成功处理后调用 `set_input_as_handled()`，防止同一次 `E / Enter` 被多个对象消费。

## 4. 视觉方向

### 4.1 普通传送阵

- 保留现有青蓝轮廓作为识别色；
- 增加双层机械环、地面基座、中心能量薄膜、缓慢旋转刻度与少量向心粒子；
- 未激活时低亮，玩家靠近后环体提亮并加速一小段，不持续高频闪烁。

### 4.2 隐藏入口

- 使用紫色裂隙、断续符文和轻微空间错位，与普通青色门区分；
- 未探索时不直接显示秘室真名，避免提前剧透；
- 已满足能力时符文闭环，条件不足时环体缺口保持断裂。

### 4.3 下行竖井

- 保留阶段 10.6 已完成的机械井沿、悬链、雾气、箭头和镜头缓降；
- 只把触发方式从碰撞即进入改为主动交互，不削弱现有竖井过场。

## 5. 代码结构

新增独立的 `portal_interaction.gd`，职责限定为：

- 保存入口元数据和当前附近玩家；
- 管理提示条显示与文本；
- 响应 `interact` 并发出 `travel_requested`；
- 提供条件不足反馈；
- 不直接重建房间、不管理存档。

`main.gd` 保留房间切换权：收到 `travel_requested` 后复用 `_on_door` 的条件检查、`call_deferred` 物理安全纪律，以及 `_play_shaft_transition` / `_enter_room` 两条现有路径。

普通左右门继续使用现有自动区域。这样可以把输入与提示从已经较大的 `main.gd` 中隔离，同时复用经过 QA 的换房流程。

## 6. 存档与兼容

- 不新增强制存档字段；
- 不修改现有 `visited`、`collected`、`permanent_chests` 或能力数据；
- 七个秘室 ID、返回门、宝箱和记忆核心全部保留；
- 旧存档可直接继续；
- 房间切换成功后仍由现有逻辑记录访问状态。

## 7. 测试与验收

### 7.1 自动契约

新增阶段 10.9 契约测试，至少验证：

1. 普通左右门保持自动模式；
2. 上门、下门和隐藏门默认进入交互模式；
3. `trigger_mode` 可显式覆盖默认值；
4. 七个隐藏入口仍全部指向阶段 10.8 秘室；
5. 交互入口复用 `interact`，输入映射仍包含 `E / Enter`；
6. 条件不足不会发出旅行请求；
7. 成功请求只发出一次，避免长按或区域重叠造成重复换房。

测试必须先失败，再实现最小代码使其通过。

### 7.2 Godot 实跑与截图

按项目 `godot-capture` 规范至少抓取并实际查看：

- 中央车站通往虚空要塞的普通传送阵提示；
- 一个未满足能力的隐藏入口锁定提示；
- 一个已满足能力的隐藏入口可进入提示；
- 暗影王城下行竖井的 `[E / Enter]` 提示；
- 按键后的目标房间实际画面。

逐次扫描全部 `ERROR` / `SCRIPT ERROR`，排除技能文档允许忽略的退出噪音后必须为 0。

## 8. 明确不在本批范围

- 世界地图任意节点快速旅行；
- 新增超过现有七个秘室的隐藏关卡；
- 装备分类页、角色纸娃娃和装备属性重做；
- 全区域美术资产替换；
- 手柄图标和可重绑定键位 UI。

上述内容分别作为后续独立规格推进。
