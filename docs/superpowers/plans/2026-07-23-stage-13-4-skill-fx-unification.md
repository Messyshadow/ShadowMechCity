# 阶段 13.4：打击 / 技能特效统一实施计划

## 目标

在不推翻现有程序化特效与六武器技能逻辑的前提下，建立可复用、可控预算、不会遮挡危险提示的技能特效语言。六类武器必须一眼可辨，普通技能、爆发技与终结技必须有清晰的强度阶梯。

## 视觉规范

每次主动技能由四层构成：

1. **预警层**：先于攻击主体出现，说明方向、范围或落点。
2. **攻击主体层**：表现武器运动轨迹与主要能量形状。
3. **命中层**：继续复用 13D.2 的材质命中系统，只在真实命中时出现。
4. **残留层**：低透明度余波、蒸汽、裂纹或轨迹，快速衰减。

层级固定为：残留 17、攻击主体 23、预警 28、命中 31。预警不被场景装饰或技能主体遮挡；全屏闪光透明度不超过 0.26，普通技能粒子预算不超过 36，终结技不超过 52。

六武器视觉身份：

- 刀剑：青蓝新月、细长剑气、电弧余迹。
- 铁锤：琥珀方形冲击、地裂、沉重尘环。
- 蒸汽枪炮：冷白蒸汽锥、直线炮焰、压力雾。
- 双刀：青紫交叉刃光、镜像残影、短促环切。
- 长枪：金色长轴菱形、贯穿线、螺旋尾迹。
- 弓弩：红绿准星、扇形射界、细线弹道。

## 实施步骤

1. 新增 `scripts/skill_fx_profile.gd`，集中保存六武器色板、形状、强度阶梯、层级和预算。
2. 在 `scripts/fx.gd` 增加预警、主体、残留三类程序化绘制函数，以及统一 `layered_skill` 入口；实际命中仍由 `combat_impact` 负责。
3. 在 `scripts/player.gd` 增加单一技能特效入口，让 ground / upper / dash_atk / burst / ultimate 都经过统一分层，减少重复全屏闪光与无差别圆环。
4. 在 `scripts/main.gd` 增加 `SHOT_13_4` 确定性抓图入口，支持六种武器逐一展示爆发技。
5. 新增 `tests/test_stage_13_4.gd`：校验六配置差异、四层顺序、预算上限、玩家接入和抓图入口。
6. 运行全部阶段测试与主场景错误扫描；使用源码 Godot 和 godot-capture 抓取六武器实际 PNG，逐张检查遮挡、构图、强度和辨识度。
7. 修复目视问题，撰写 `docs/qa/13.4-review.md`，更新 `docs/DEV_PLAN.md`，导出到发布目录并提交 Git。

## 验收标准

- 六种武器在无文字辅助时仍可通过颜色与形状区分。
- 技能预警始终清晰，攻击主体和全屏闪光不会遮挡敌方危险提示。
- 普通、爆发、终结三个强度档位可感知但不越过预算。
- 实际命中继续按血肉 / 金属 / 岩石 / 护盾 / 虚空材质反馈。
- 契约测试、主场景扫描、发布版直启均无 `ERROR` / `SCRIPT ERROR`。
- 六武器实际 PNG 完成目视验收并记录在 QA 报告中。
