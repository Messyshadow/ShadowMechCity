# 13.6 分区域动态配乐与环境音验收

日期：2026-08-20

## 交付内容

- 新增统一 `RegionAudioController`，房间切换时按中央车站、废铁矿坑、蒸汽铸造厂、腐化水道、遗迹神殿、虚空要塞和暗影王城切换音频身份。
- 七区分别使用冷钢序曲、岩层脉冲、过压锻炉、沉没回声、星轮祭仪、裂隙风暴与君王挽歌配置；通过有效的曲目时间切片、音高和音量形成地区化编曲。
- 两路音乐播放器执行 1.15 秒无缝交叉淡入淡出，房间切换不再硬切。
- 探索、战斗、Boss 三级强度会渐变调整配乐音高、响度与环境层。
- 使用 `AudioStreamGenerator` 实时合成轨道低鸣、矿脉敲击、蒸汽机组、水下气泡、符文钟声、虚空风噪和王城风琴七类环境层。
- 新增 `SHOT_REGION_AUDIO=<theme>` 与 `SHOT_AUDIO_INTENSITY=0|1|2` 验收入口，PNG 直接显示当前区域、编曲、环境层、强度、音高和音量。
