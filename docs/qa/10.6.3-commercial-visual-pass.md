# 10.6.3 王城/虚空与下行入口商业化精修验收

日期：2026-07-12

## 审计结论

10.6.2 功能可用，但实际截图仍存在三类问题：王城复用神殿柱廊、虚空复用工厂背景；镜头边缘会露出默认灰底；通用下行口仅 120px，井沿由大量临时 Line2D 拼成，地形阅读偏弱。王城炮骑和风暴法师还复用了蘑菇法师底图，与暗黑机械主题冲突。

## 本轮改动

- 新增 `scripts/theme_backdrop.gd`：王城使用暗紫城塔、哥特拱廊、玫瑰窗与悬链；虚空使用深蓝星尘、核心裂隙、舰体肋骨与冷色窗光。
- 所有主题增加固定负层级的全画布底色层，消除镜头边缘灰底，同时保证 HUD 不被背景遮挡。
- 新增 `scripts/downward_portal_visual.gd`：下行口扩大到 180px，以实心井沿、收束井壁、梯级、防坠栅残片和低矮护栏表达可下落地形。
- 只有深度不小于 500px 的场景竖井保留长井绘制；王城普通房间不再把短竖井与地面入口重复叠加。
- 10.6 敌人增加盾/枪/炮/法师角色附件层；炮骑改用机械魔像底图，风暴法师改用悬浮机械体，虚空鹰改用灰色飞龙底图，移除最突兀的蘑菇法师轮廓。
