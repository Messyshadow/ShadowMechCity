## 交付范围

- 中央车站 x=704 新增实体“轨道量子升级台”，具备独立机械轮廓、扫描环、卫星链路光柱、近场检测和高对比 `[E] 量子升级` 提示；不会遮挡五名既有 NPC，也不改变房间碰撞或旧路线。
- 新增三栏升级界面：左栏按“全部装备 / 防具 / 饰品”列出装备中与库存硬件，中栏播放卫星储能量子投射，右栏显示厂商、定位、稳定实例 ID、属性前后值、补丁阶段和金币报价。
- 选择与交易只使用 `item_instance_id`，不依赖背包数组下标；装备换槽或排序后仍能找到同一硬件。
- “请求卫星投射”先校验余额，再进入“确认升级 / 取消”二次确认。余额不足会明确拒绝且不修改装备和金币；取消也不扣款。
- `Game.apply_equipment_patch()` 在确认后执行原子事务：重新验证装备与余额、扣除 `Game.coins`、增加 `patch_level`、同步旧 `lv`、追加补丁历史、发出装备/成长信号并立即 `save_game()`。
- 投射演出包含轨道卫星、扫描束、旋转数据环、核心粒子、拒绝红态与成功绿态；全部由 Godot 程序化绘制。
- 存档版本保持 v17，本批没有重复升级版本，也没有重刷旧装备。
