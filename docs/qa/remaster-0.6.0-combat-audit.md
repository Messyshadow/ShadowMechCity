# 0.6.0 战斗反馈核查

日期：2026-09-19（上海）。用户询问近战连击、空中连斩、双方受击和格挡。本次检查现有行为，没有实现新玩法，也没有更新 Windows 发行包或版本号。

## 结论

| 项目 | 当前实现 | 待补内容 |
| --- | --- | --- |
| 地面连击 | 长刀、重锤、长枪 3 段；拳套、双刀 4 段；支持连按衔接，命中有特效及停顿 | 武器动作差异、重量感及收尾；锤/枪多段仍复用相似姿态逻辑 |
| 空中连斩 | 可以连续发动空中攻击，但同一武器每次使用同一个 air 动画；拳套上挑能抬升玩家和普通敌人 | 独立多段动作、衔接窗口、浮空追击及终结动作 |
| 敌人受击 | 受击动画、闪色、短暂停顿、普通敌人硬直/击退、伤害数字和音效调用 | 普通受击、重击、盾挡、破防的明显区别；Boss 动作与受击状态协调 |
| 玩家受击 | 扣血、击退、闪烁、短暂无敌、镜头震动和受伤音效调用 | hurt 动画没有接入；测试中挨打后播放 jump；没有明确受击状态及攻击中断规则 |
| 格挡 | 盾卫敌人正面减伤 60%，收招或被绕后时可正常受伤 | 玩家主动格挡/弹反未实现；盾卫挡击仍使用普通 hurt、闪色及音效，缺独立格挡与破防表现 |

`actor.gd` 的近战命中停顿目前暂停角色物理处理，但没有暂停 AnimationPlayer；`enemy.gd` 则会在 hit_stop 时将动画速度归零。第三段伤害倍率为 1.5，拳套/双刀第四段没有单独的终结增伤。不能仅凭段数宣称连击手感已精修。

## 实机诊断

脚本：[capture_combat_audit.gd](../../remaster/tests/capture_combat_audit.gd)。Godot 4.7.rc，RTX 5070 Laptop，Vulkan Forward+，1280×720，固定 60 Hz；隔离存档，关闭持久化。地面/空中攻击使用实际 Input 动作；受击和盾挡直接调用伤害入口以隔离判定。敌人作为高生命、暂时停止攻击的诊断靶，镜头固定，截图不代表正常敌人战斗决策。

运行退出 0，七张截图保存成功。日志：[stdout](../../remaster/qa/combat_audit.log)、[stderr](../../remaster/qa/combat_audit_errors.log)。扫描所有 ERROR，仅有已知本机 `Failed to read the root certificate store`。这不是新增功能通过验收，不能计入此前 934 项测试数量。

- 地面实际动画序列：blade_1/2/3、hammer_1/2/3、gauntlet_1/2/3/4、dual_1/2/3/4、spear_1/2/3。
- 空中双刀连续两击都播放 `air_dual`。
- 玩家 120 HP 受到 20 点伤害后为 100，2 个物理帧后动画为 `jump`，仍有击退与无敌时间。
- 盾卫正面接收 20 点攻击，实际伤害 8；收招时同样攻击伤害 20。盾挡同时触发 `hurt`、普通闪色、0.23 秒硬直。
- 输入表中没有 r_guard、r_block 或 r_parry，代码核查也未发现玩家主动格挡状态。
