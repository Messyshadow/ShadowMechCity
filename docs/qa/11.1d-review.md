日期：2026-08-30

## 交付范围

- 新增统一 `SummonFx` 程序化表现层：量子投射、回收压缩、损毁爆发、职责技能预警均采用暗黑机械城的青/橙/绿/红能量色，不依赖新增外部素材。
- 先锋、盾卫、炮击、修复四种职责分别使用斩击弧、冲击扇区、目标激光/准星、修复轨道/十字预警；攻击和治疗由“起手预警 → 延迟结算”替代瞬时命中。
- 每个特效均自动淡出释放；全局同屏特效根节点设 18 个硬上限，控制器持续记录峰值，防止三机与 Boss 技能叠加时无限生成节点。
- 部署槽位具有编号、扫描线、双环与垂直投射束；回收、损毁使用独立轮廓，战斗中能一眼区分状态。
- 新增 Boss 同屏压力 QA 钩子与性能快照。三台伙伴同时攻击“岩核机甲巨兽”时实测：`active=3`、`peak_fx=10/18`、`fps=240`，未超过召唤数量或特效预算。
- 修复实机压力测试发现的问题：通用敌人有 `dead`，Boss 使用 `state == "dead"`；召唤索敌现同时兼容两种死亡协议，不再产生连续 `Invalid call. Nonexistent 'bool' constructor`。
- 存档继续使用 v16，本批未改变存档结构、阵容上限、机器人稳定 ID 或旧关卡协议。
