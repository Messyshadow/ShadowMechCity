# 10.6.1 通用下行竖井入口验收

日期：2026-07-11
范围：修复旧区域（特别是地下水道）仍使用简陋地面洞口的问题。

## 实现

- 所有 `side: "down"` 房间门统一生成可见的机械竖井入口：拱形金属框、内层深井、悬索、下层标识与上浮雾粒。
- 入口根据区域主题上色：水道青蓝、矿坑锈橙、神殿金色、工厂橙红、虚空/王城紫色。
- 王城已有的手工深井保持原样，避免重复叠加通用入口。
- 所有向下门均使用下落镜头过渡，修正此前仅王城竖井生效的限制。

## 自动验证

- `tests/test_downward_portals.gd`：输出 `PASS downward portal coverage`。
- 实际运行水道与矿坑截图时，ERROR / SCRIPT ERROR 扫描为空，进程退出码为 0。

## 截图目视验收

| 房间 | 结果 |
| --- | --- |
| 地下水道（`depths`，x=300） | 通过：原地面黑洞改为青蓝金属拱架和收束深井，入口位置清晰。 |
| 废弃矿坑（`mine`，x=1080） | 通过：同一入口使用锈橙框架，与矿坑背景和熔铁色调一致。 |

结论：通过。后续商业化美术阶段可将程序化竖井替换为统一绘制的主题 tileset，但当前所有旧下行通道已具备清晰、可读的入口语言与镜头反馈。
