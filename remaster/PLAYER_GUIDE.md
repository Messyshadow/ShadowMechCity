# 暗影机械城 · 重铸余烬 — 0.5.0 Windows 开发试玩版

完整解压下载包，再运行 **ShadowMechCityReforged.exe**。EXE 与 PCK 必须位于同一目录。游玩不需要安装 Godot 或 Blender。

## 操作

| 按键 | 功能 |
|---|---|
| A/D、方向键左右 | 移动 |
| 空格 | 跳跃、二段跳；贴墙时蹬墙跳 |
| W/S、方向键上下 | 楼梯、检修梯、升降机、排水管 |
| Shift / L | 冲刺 |
| J / K | 普通连击 / 已学习的本武器终阶技能 |
| Q / T | 切换武器 / 技能树，树中也可直接装备武器 |
| R / H | 装填 / 使用治疗剂 |
| E | 交互、交易、同步存档、进入横向房间入口 |
| C / G | 部署或回收伙伴 / 阵容 |
| I / U、M、N | 背包 / 地图 / 任务 |
| Esc / F11 | 暂停或关闭面板 / 全屏 |

## 开始旅程

先在中央车站的青色终端按 E 同步，再找拾荒商人赫克领取吸血护符。终端补给生命、最低药剂和弹药，并决定死亡后的返回位置。切换房间不会更换这个重生点。

巡线员莉娅的委托指向晨曦温室。N 查看目标，M 查看完整房名、缩放或拖动地图。橙色光圈和地面标记提示敌人的攻击；等出招落空后再反击。

## 武器与伙伴

- 七类武器：长刃、重锤、蒸汽炮、拳套、双刀、长枪、弓弩。试玩阶段可直接选择各家族；原版的全部变体与探索解锁尚未迁完。
- 三大技能分页共 33 节点。先学前置再学后续，第三阶解锁 K。蒸汽炮与弓弩共用 8 发弹匣和有限备弹，购买弹药或回终端补给。
- C 部署伙伴，G 选择四种机器人。初始一个出战位，第二、第三位分别消耗 2、3 技能点，同型号不能重复。
- 先锋犬近战，壁垒鼹重装护卫，天轨蜂远程射击，流明萤治疗。伙伴有独立生命，损毁后在游玩时间内重构 12 秒；回收或切房不会立刻修好。
- 多机降低单机输出，热量满会暂停攻击/修复 2.4 秒。菜单暂停期间不会偷偷结算战斗。

## 装备与设置

背包显示六槽装备、替换属性与强化。商店可以购买、出售和一键回收未装备白装，已售装备可从独立回购页找回，保留原属性及强化等级。

主菜单或暂停菜单中进入设置，可以调整全屏、总音量、音乐、效果、环境音、亮度、震动和教学。偏暗时先调整场景亮度。

## 存档

重制存档名为 `remaster_v1.json`，备份为 `.bak`。Windows 默认位置在 `%APPDATA%\Godot\app_userdata\暗影机械城 - 横版动作Demo`。重制版使用独立文件，不覆盖 2D 原版的 `save.json`。

0.5.0 会检查存档结构，并尝试从有效备份恢复。若全部不可读取，将暂停自动保存并提示处理。重新开始前会先保存损坏文件副本；复制失败时不会建立新进度。恢复文件前先退出游戏，并保留整个存档目录。

## 版本边界与反馈

这是开发试玩版，现有 40 房间、七 Boss、七武器家族和四种伙伴。原版全部任务/NPC、探索机关、部分技能、量子升级、黑客与虚拟空间仍在推进；模型、动作、音效和数值仍需精修。完整人工通关、多硬件长时间性能、手柄及按键重绑尚未完成。
