# 0.2.0 重制开发版验收记录

日期：2026-09-18。用户最后确认“继续重制，能完成多少算多少”。本轮交付一份可以直接运行的增量开发版，未将完整游戏的最终重制标记为完成。

## 本轮可玩内容

- 新建 12 套 Blender 角色资产，保留 `.blend`、骨架、动画及生成脚本。人形包括猎魂者、商人、步兵、炮兵、泰坦、盾卫、骑士和君王；飞行机、四足岩核兽、巨鳄及天龙使用不同的骨架／外形。天龙包含双翼与尾部关节。
- 角色资源各带 36 个命名动作片段（原为 13）。玩家的长刃、重锤、四连拳、升龙、空中攻击、射击、装填、爬梯和楼梯行走接入对应动画。技能面板选择节点时显示对应动作，拳套有左右两件模型。
- 8 个新 Blender 建筑模块：工业桁架、岩壁、涵洞、拱廊、站钟、虚空环、旗帜、壁灯。运行时模型总数 42。七区域采用不同的背景构图和灯光，矿坑／水道岩壁降低亮度以突出玩家。
- 37 个房间接入独立于旧 2D 坐标的平台配置。重排敌人和奖励落点，避开坑口和井口。增加楼梯、排水管视觉与动作；上下梯井和升降机保留。楼梯可以中途反向退回，抵达邻接房间时选择安全落脚位置。
- Boss 编排增加泄压喷口、符文落点、落石、巨鳄撕咬／甩尾／潮汐、天龙俯冲、骑士突刺／连斩、君王裂隙。延迟招式有可见预警和反击窗口；Boss 死亡清除待触发的伤害。
- 定向弧形刀光替代整圆环；蒸汽／符文／电弧机关先亮地面预警，再释放有高度限制的伤害。打开菜单冻结角色及敌人的动画和延迟攻击。
- 背包新增六槽概览、替换属性差值、最高 +5 强化和价格提示。强化不提高吸血率；出售／回购及保存重载保持 UID 和强化属性。10 张装备图标重新用 Blender 渲染为 512×512。
- 新增 7 个区域及 1 个 Boss 的原创合成循环配乐，24 kHz 立体声；修复机械循环音静音后不能恢复的问题。原有动作音效本轮未换成录音拟音。

## 画面检查后修正

1. 修正玩家武器闲置朝向和炮口方向；射击位置跟随实际炮口，首段碰撞同时检测玩家到炮口之间，避免近身敌人位于炮口后方时漏击。
2. 骑士和君王的待机剑尖原先穿过地板，调整为向前抬起的持剑姿态。
3. 原坑上跳台遮挡楼梯，改为完整开口，移开重叠跳台，取消井下的发光假熔岩；角色和台阶可见。
4. 敌人原坐标可能落在新坑上方，改为根据当前地形选取安全地面。
5. JSON 读档将整数变成浮点，现对装备 UID、价格、品质和强化等级恢复整数类型，避免 `+5.0` 显示及比较不一致。

## 仍需继续

- 当前是程序建模的风格化机械美术；材质、轮廓、蒙皮和动作仍需精修，不能视为参考图级别的成品美术。原始参考图片未在本任务中取回。
- 37 房间采用新的平台规则和区域配置，但尚未逐房制作最终版本的独特谜题、镜头调度及完整探索节奏。保留了旧世界的房间名称和拓扑。
- 部分 Boss 和敌人仍复用基础动作及状态机；需要进一步打磨专属连招、受击表现和高难度平衡。
- 旧版召唤伙伴、更多旧武器技能及完整剧情演出尚未迁入本轮；地图沿用已有的完整名称／缩放／拖动系统。
- 音乐和声音仍以合成为主；尚未进行人工听音混音验收、录制拟音或长时间疲劳度测试。
- 未进行完整人工通关、长时间稳定性／多硬件性能测试。正式发布与 Git 交付记录见 [发布验收](RELEASE_0_2_0.md)。
