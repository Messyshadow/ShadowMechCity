## 本轮修正的通行缺陷

1. 出生点附近低平台抬升，避免平台顶头影响新手跳跃。
2. 破碎甲板和中央车站加入实体双向升降井，验证往返。
3. 骑士竞技场与君王升降井的上下入口错开，避免抓错通道。
4. 跌落下井后，在井底按 S 仍可进入下层。
5. 水平出口与存档终端距离过近时，E 改为选择更近的交互对象，修复铸造厂入口返回矿坑的交互冲突。
6. 修正背包浮点属性显示，验证实际菜单截图。

## 实际限制

自动检查并非完整人工通关；没有进行长时间、多种硬件的性能测试。当前视觉为风格化机械模型，未达到用户参考图的写实精度。旧召唤伙伴和装备强化仍在原 2D 版，新系统采用四武器/12 技能的独立设计。

此沙箱环境的引擎启动会打印 `Failed to read the root certificate store`，但最终测试、导出及独立版运行均正常完成；该消息不是游戏脚本错误。本游戏运行不依赖网络。
